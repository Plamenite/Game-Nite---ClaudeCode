# Gamenite mobile app

The iPhone (and later Android) app, built with Expo and React Native.

Run it from the repo root with `npm run mobile`, then scan the QR code with
the Expo Go app on your iPhone. See the root README for the full guide.

- `src/app/` — screens. Each file is a screen; folders are navigation groups.
- `src/components/` — reusable pieces of UI.
- `src/constants/theme.ts` — colours, fonts, spacing (light + dark mode).
- `app.json` — the app's identity: name, icon, Apple bundle identifier.
